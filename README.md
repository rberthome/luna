# Luna — chatte perdue à Palaminy

Site : https://rberthome.github.io/luna/

## Mettre à jour le bandeau « Dernière trace »
Éditer `index.html`, chercher `statut-texte`, remplacer le texte, puis :
```
git add -A && git commit -m "maj observation" && git push
```

Fichiers : `index.html` (site), `affiche.html` (A4 à imprimer), `visuel.html` (source du visuel carré réseaux).
